# auto-subagent-leader

Cursor Agent Plugin: thin Auto parent routes work to specialist subagents (Fable / Opus / Sol).

This is a **skill plugin**, not an MCP server. Install from Cursor Marketplace (or Team Marketplace Required) so Cloud Agents and [cursor.com/agents](https://cursor.com/agents) load it. A laptop `~/.cursor/plugins/local` copy does **not** reach Cloud VMs.

Slash: `/auto-subagent-leader`

## Install

1. Public listing after review: [cursor.com/marketplace](https://cursor.com/marketplace)
2. Or Team Marketplace → installation mode **Required** (Cloud-wide)
